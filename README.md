# AI-Powered Educational Video Generator

An automated pipeline designed to generate high-quality educational videos (specifically tailored for language learning) using AI-generated scripts, voiceovers, images, and subtitles. The system transforms a simple concept into a fully composed video ready for platforms like YouTube.

## 🚀 Overview

This project automates the entire content creation lifecycle. By providing basic parameters (such as characters, locations, and learning objectives), the pipeline handles scriptwriting, audio synthesis, visual asset generation, video composition, and even the final upload process.

## 🏗️ Pipeline Architecture

The generation process follows a sequential, modular pipeline where each step relies on the output of the previous one, coordinated by a central manifest file.

### 1. Script Generation (`create_script.py`)
The process begins by generating a structured narrative. Using LLMs, the system creates a script containing:
- **Scene Text:** The dialogue between characters.
- **Learning Points:** Specific educational objectives for the viewer.
- **Metadata:** Character descriptions and location details required for visual consistency.

### 2. Project Initialization (`create_project.py`)
A project directory is initialized, and a `manifest.json` file is created. This file serves as the "Single Source of Truth" for the entire pipeline.

### 3. Audio Synthesis (`create_audio.py`)
The script text is processed to generate high-quality Text-to-Speech (TTS) audio. The system generates separate audio files for each character and narrator, ensuring distinct voices for different roles.

### 4. Visual Asset Generation (`create_images.py`)
Using the character and location descriptions from the manifest, the system interfaces with image generation models (like DALL-E) to create consistent visual assets. It generates:
- Character portraits.
- Location backgrounds.
- Over-the-shoulder shots and cutaway images to maintain visual interest.

### 5. Video Composition (`create_video.py` & `assemble_video.py`)
The pipeline enters the assembly phase:
- **Clip Creation:** Individual video clips are generated by animating the synthesized images, syncing them with the generated audio, and overlaying dynamic subtitles.
- **Final Assembly:** All individual clips are stitched together, background music is added, and branding (watermarks/intros) is applied to create the final production.

### 6. Distribution (`upload_video.py`)
Once the video is rendered, the system can automatically upload the finished product to YouTube, complete with optimized titles, descriptions, and tags.

## 📄 The Manifest File

The `manifest.json` is the core orchestrator of the project. It tracks every asset, path, and piece of text generated during the pipeline. This allows the pipeline to be interrupted and resumed, or to re-run specific modules (like re-generating images without re-generating audio).
